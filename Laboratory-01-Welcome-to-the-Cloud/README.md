# Laboratory 01 - Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the basics of cloud-based
Linux environments, Linux commands, system information, and
GitHub repository management.

## Objectives

- Access a cloud-based Linux environment.
- Use basic Linux commands.
- Gather system information.
- Create and organize files and directories.
- Document laboratory activities using Markdown.
- Create and manage a GitHub repository.

## Activities Performed

- Launched an Ubuntu Linux Playground using KillerCoda.
- Created a new Linux user account.
- Checked Linux system information.
- Created directories and Markdown files.
- Created a GitHub repository.
- Uploaded laboratory files and screenshots.

## Linux Commands Used

- whoami
- pwd
- hostname
- useradd
- passwd
- usermod
- su
- cat
- uname
- lscpu
- free
- df
- mkdir
- cd
- ls
- nano

## Skills Learned

I learned how to use a cloud-based Linux environment,
manage users, navigate the Linux file system, collect
system information, create Markdown files, and organize
my laboratory work in GitHub.
