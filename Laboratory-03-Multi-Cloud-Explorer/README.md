# Laboratory 03 – Multi-Cloud Explorer

## Linux Server Investigation

The KillerCoda Linux playground was inspected using Linux commands to identify the operating system, CPU, memory, and disk space.

### Linux Commands Used

- `cat /etc/os-release` – identifies the operating system.
- `lscpu` – displays CPU information.
- `free -h` – displays memory information.
- `df -h` – displays disk space information.

## Possible Cloud Hosting Services

| Cloud Provider | Service |
|---|---|
| AWS | Amazon EC2 |
| Microsoft Azure | Azure Virtual Machines |
| Google Cloud | Compute Engine |

A Linux server can be hosted on virtual machine services from AWS, Azure, or Google Cloud. These services provide configurable virtual machines where a Linux operating system can run applications and workloads.
