# AWS Research

## 1. Brief Overview

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of services for computing, storage, databases, networking, security, and other cloud needs.

## 2. Global Infrastructure

AWS operates a global infrastructure made up of Regions and Availability Zones. AWS currently has 39 geographic Regions and 123 Availability Zones. Each AWS Region contains multiple isolated Availability Zones, which help provide high availability and fault tolerance.

## 3. Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can use the console to create, configure, monitor, and manage cloud resources.

## 4. Four Core Services

### Amazon EC2
Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and workloads.

### Amazon S3
Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve data.

### Amazon RDS
Amazon Relational Database Service (RDS) makes it easier to set up, operate, and manage relational databases in the cloud.

### Amazon VPC
Amazon Virtual Private Cloud (VPC) allows users to create a logically isolated network for their AWS resources.

## 5. Three Advantages

1. AWS provides a wide variety of cloud services for different business and technical needs.
2. Its global infrastructure supports applications that require scalability and high availability.
3. AWS allows organizations to deploy applications in different geographic locations.

## 6. Typical Enterprise Use Cases

AWS can be used by enterprises for web and mobile applications, data storage and backup, database hosting, e-commerce systems, artificial intelligence and machine learning, and large-scale business applications.
