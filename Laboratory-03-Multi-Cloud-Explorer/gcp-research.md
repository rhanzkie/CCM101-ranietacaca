# Google Cloud Platform Research

## 1. Brief Overview

Google Cloud Platform (GCP), also known as Google Cloud, is a cloud computing platform that provides services for computing, storage, databases, networking, security, artificial intelligence, and application development.

## 2. Global Infrastructure

Google Cloud operates a global infrastructure consisting of regions and zones. Regions are geographic locations where Google Cloud resources can be deployed, while zones are isolated locations within a region.

## 3. Cloud Management Console

The Google Cloud console is a web-based interface used to create, configure, monitor, and manage Google Cloud resources and services.

## 4. Four Core Services

### Compute Engine

Compute Engine provides configurable virtual machines that can be used to run applications and workloads.

### Cloud Storage

Cloud Storage is an object storage service used to store and retrieve data in Google Cloud.

### Cloud SQL

Cloud SQL is a fully managed relational database service for databases such as MySQL, PostgreSQL, and SQL Server.

### Google Kubernetes Engine

Google Kubernetes Engine (GKE) is a managed Kubernetes service used to deploy, manage, and scale containerized applications.

## 5. Three Advantages

1. Google Cloud provides strong capabilities for artificial intelligence and machine learning.
2. Google Cloud provides managed Kubernetes services through Google Kubernetes Engine.
3. Its global infrastructure supports applications and workloads that need scalable cloud resources.

## 6. Typical Enterprise Use Cases

Google Cloud is commonly used for artificial intelligence and machine learning, data analytics, containerized applications, web applications, database systems, and large-scale digital services.
