# Mission 3 Reflection

During this mission, the cloud platform that impressed me the most was Google Cloud because of its strong focus on artificial intelligence, machine learning, data analytics, and Kubernetes. I learned that each cloud provider has different strengths, so choosing a provider should depend on the actual needs of an organization.

AWS, Microsoft Azure, and Google Cloud have many similarities. All three provide computing, storage, networking, databases, identity management, and other cloud services. They also provide global infrastructure that allows organizations to deploy applications and services in different locations.

Business requirements strongly influence cloud platform selection. For example, a university that already uses Windows Server, Microsoft 365, and Active Directory can benefit from Azure because of its integration with Microsoft technologies. On the other hand, an AI research company may benefit more from Google Cloud because of its AI and machine learning capabilities.

Acting as a Cloud Solutions Consultant taught me that selecting a cloud provider is not simply about choosing the most popular platform. I need to understand the client's budget, existing technologies, workload requirements, scalability needs, and business goals before making a recommendation.

I added organized research files, comparison tables, client recommendations, screenshots, and Linux investigation results. This activity helped me practice technical documentation using Markdown and made my repository more organized and useful as a record of my cloud computing learning.
